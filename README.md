# Asif Akbar — Developer Portfolio

A personal portfolio website showcasing my work, skills, and experience as a MERN Stack Developer. Built to give a complete overview of my projects, technical skills, and professional background to potential employers and clients.

🔗 **Live Site:** [asif-ali-portfolio-xi.vercel.app](https://asif-ali-portfolio-xi.vercel.app/)

## Sections

- **About** — Introduction and background
- **Skills** — Technical stack and tools I work with
- **Projects** — Showcase of featured work, including [Hotelify](https://hotelify-cyan.vercel.app/) (multi-tenant hotel booking SaaS) and other MERN stack projects
- **Experience** — Professional work history
- **Contact** — Ways to get in touch

## Tech Stack

**Frontend:** React.js, Tailwind CSS  
**Deployment:** Vercel

## Features

- Fully responsive design across devices
- Clean, modern UI to highlight projects and skills
- Direct links to live project demos and GitHub repositories

## Getting Started

### Installation

```bash
git clone https://github.com/asifakbar-aruxstudio/asif.ali.portfolio.git
cd asif.ali.portfolio
npm install
npm run dev
```
